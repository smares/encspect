# Encspect 0.1.0

The first release. It is marked as a pre-release: the formats below are read in depth, but the project is in development and the lossless formats are not read yet.

## What Encspect is

- **Audio file analyzer:** reports everything technically knowable about an audio file's structure: encoder and writer detection, bitrate behavior, bit reservoir use, VBR headers, tags and more.
- **Traceable:** every reported value points back to the bytes it came from, with their offset and length.
- **Two front ends:** `encspect`, a command line tool, and `encspect-gui`, a GUI with a structure tree next to a hex view.
- **No verdicts:** the report says what the file shows, never whether it sounds good.
- **Damaged files:** a damaged or odd file produces findings, not a crash.

## What it reads

Formats ([details](https://github.com/smares/encspect/blob/v0.1.0/docs/formats/README.md)):

- MPEG audio: MP1, MP2 and MP3, with VBR headers, mp3PRO, MP3 Surround and MPEG-2 multichannel
- MP4, M4A, M4B, 3GP and QuickTime files
- AAC in MP4, ADTS and ADIF, including HE-AAC, HE-AAC v2 and xHE-AAC
- Ogg, with Speex, Vorbis and Opus
- Musepack SV4 to SV8
- AC-3 and E-AC-3, raw and in MP4, with the object audio (JOC) that Dolby Atmos adds
- DTS (core, XCh, X96, XXCH and the DTS-HD extension substreams), raw and in MP4, and DTS-HD files (`.dtshd`)
- WavPack (lossless, hybrid and DSD), `.wv` and `.wvc`
- ASF (`.wma`, `.wmv`, `.asf`) with Windows Media Audio versions 1 and 2, Professional and Voice, and Lossless at header level
- Matroska and WebM (`.mka`, `.mkv`, `.webm`) with AAC, AC-3, E-AC-3, DTS, Vorbis and Opus audio

Tags ([details](https://github.com/smares/encspect/blob/v0.1.0/docs/tags/README.md)): ID3v1, ID3v2, APE, Lyrics3 and Vorbis comments.

Protection: streams that a container encrypts or locks are reported with their scheme and DRM systems, without decrypting.

## Downloads

Each archive holds the command line tool, the GUI, the license, the third-party notices and a short README. Archives are named `encspect-0.1.0-<platform>`; `SHA256SUMS` lists their checksums.

| Platform | Archive | Built on |
|---|---|---|
| Windows, x64 | `encspect-0.1.0-win-x64.zip` | `windows-latest` |
| Windows, ARM64 | `encspect-0.1.0-win-arm64.zip` | `windows-11-arm` |
| macOS, Apple silicon | `encspect-0.1.0-osx-arm64.tar.gz` | `macos-latest` |
| macOS, Intel | `encspect-0.1.0-osx-x64.tar.gz` | `macos-15-intel` |
| Linux, x64 | `encspect-0.1.0-linux-x64.tar.gz` | `ubuntu-26.04` |
| Linux, ARM64 | `encspect-0.1.0-linux-arm64.tar.gz` | `ubuntu-26.04-arm` |

- **Self-contained:** each program is one file that carries the .NET runtime. Nothing needs to be installed for the command line tool.
- **Checked on its own platform:** each build was published, and its programs were run, on a runner of that platform before packaging. The GUI ran its self-check, which loads its native libraries and analyzes a file without showing a window; on Linux that includes the X11 and Wayland backends under a headless compositor.
- **Checksums:** `sha256sum --check SHA256SUMS` on Linux, `shasum -a 256 -c SHA256SUMS` on macOS.

## Running it

Unpack the archive, then:

```sh
./encspect song.mp3              # text tree; --json, --ndjson and --csv for the other outputs
./encspect --version
./encspect-gui                   # the GUI; it also takes files and folders as arguments
```

On Windows these are `encspect.exe` and `encspect-gui.exe`. Options are in the [command line](https://github.com/smares/encspect/blob/v0.1.0/docs/cli.md) and [GUI](https://github.com/smares/encspect/blob/v0.1.0/docs/gui.md) documentation.

## The builds are not signed

The programs carry no code signature, so each system asks before it runs them.

- **Windows:** SmartScreen shows "Windows protected your PC". Choose "More info", then "Run anyway".
- **macOS:** Gatekeeper quarantines a download from a browser and refuses to start its programs. The GUI is a single executable, not an `.app` bundle, so it appears as a Unix program and runs from a terminal or by double-click after the quarantine is cleared. Clear it for the unpacked folder:

  ```sh
  xattr -dr com.apple.quarantine encspect-0.1.0-osx-arm64
  ```

  Use the folder's name for your download. The other route is to Control-click (right-click) the program in Finder, choose Open, and confirm; on recent macOS versions the confirmation is "Open Anyway" under System Settings, Privacy & Security.
- **Linux:** nothing is checked. The archive keeps the programs' executable bit; if a tool drops it, `chmod +x encspect encspect-gui` restores it.

## Linux libraries

The command line tool needs nothing beyond the system. The GUI draws with Skia and HarfBuzz, which are inside its file, and its two windowing backends are managed code over the system's own libraries:

- **X11, the default** (also on a Wayland desktop, through XWayland): libX11, libXrandr, libXi, libXext, libXfixes, libXcursor, libSM and libICE; libgtk-3 and libgdk-3 for the GTK file dialog when no desktop portal answers.
- **Wayland, experimental and opt-in** with `ENCSPECT_GUI_BACKEND=wayland`: libwayland-client, libwayland-cursor, libwayland-egl, libxkbcommon, libgbm and libdrm, with EGL for drawing.
- **File dialogs:** the system dialog goes through the XDG desktop portal; without one, Avalonia's own dialog appears.

Without its display, a forced backend ends with one line naming `ENCSPECT_GUI_BACKEND`, `WAYLAND_DISPLAY` and `DISPLAY`, and exit code 1.

## Known limits

- **Lossless formats:** FLAC, WAV, AIFF, ALAC, Monkey's Audio, TTA, Dolby TrueHD and MLP, and TAK and OptimFROG are not read yet. WMA Lossless is read at header level only.
- **No decoding:** no format has a decoder yet, so the GUI's waveform and spectrogram, which need decoded audio, are not there.
- **No playback and no tag editing:** by design.
- **Wayland:** native Wayland is experimental. A program cannot place its windows there, so the detail window's position is the compositor's choice.
- **Not run by a person:** the file dialogs, drag and drop and the clipboard on Wayland, and light and dark mode there, need a desktop session and were not exercised by the automated checks.
- **Unsigned builds** (above).

## What is next

- **Phase 3, the lossless formats:** FLAC, WAV, AIFF, ALAC in MP4, WMA Lossless in ASF, Monkey's Audio, TTA, and Dolby TrueHD and MLP frame by frame, with decoders that verify the stored checksums. No date is promised.
- The [plan](https://github.com/smares/encspect/blob/v0.1.0/docs/PLAN.md) has the order and what comes after.
